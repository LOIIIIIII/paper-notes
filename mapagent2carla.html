核心想法

自动驾驶仿真地图不是一张漂亮的 3D 图片。它必须同时拥有视觉资产和可驾驶语义： 道路拓扑、车道方向、junction、waypoint、spawn point、交通灯和 OpenDRIVE。

MapAgent2CARLA 的目标是让多个智能体分工协作，从多源视觉地图输入中生成 simulator-ready map，并通过 CARLA 仿真结果自动发现和修复问题。

Research Positioning Generate → Simulate → Inspect → Repair

重点不是一次性生成，而是把 CARLA 作为闭环验证环境，让地图在反复仿真和修复中变得可运行。

多智能体分工

每个 Agent 只负责一个清晰任务，并通过结构化中间表示把结果传给下一个 Agent。

01

Perception Agent

调用 SAM/SAM2、遥感道路提取、OCR、VLM 和图像配准工具，识别道路、建筑、人行道、绿地和障碍物候选区域。

02

Topology Agent

从 road mask 中提取道路中心线、lane graph、junction graph、车道方向、道路宽度、spawn point 和 waypoint graph。

03

Semantic Configuration Agent

生成统一地图配置文件，把图像理解、OpenDRIVE、3D assets 和 CARLA 仿真连接起来。

04

Builder Agent

生成 OpenDRIVE/XODR、waypoint、交通配置和 3D 视觉资产，可调用 RoadRunner、UE、Blender 或 Marble-like 模型。

05

Simulation Agent

把地图导入 CARLA，运行 route planning、交通流、车辆和行人，记录碰撞、卡死、断路和 off-road 等问题。

06

Inspector & Repair Agent

根据截图、鸟瞰图、OpenDRIVE 解析结果和仿真日志定位问题，并自动修改拓扑、OpenDRIVE 或场景配置。

闭环的价值在于，地图质量不再只由人工肉眼判断，而是由仿真运行结果约束。 如果车辆在路口卡死，Inspector Agent 需要定位是 lane connection、junction topology、 waypoint 还是障碍物摆放导致的失败，再由 Repair Agent 修改配置并重新生成。

最小可行原型

第一阶段不必做完整城市。可以从 10 到 50 个小区域开始：直路、T 字路口、十字路口、 校园道路、园区道路和停车场入口。
